# Personal Profile Webpage

A simple, responsive personal profile webpage built using **HTML and CSS**. The webpage presents personal information, skills, and projects in a clean and modern layout.

## 📁 Project Structure

```text
personal-profile-webpage/
│
├── index.html
├── style.css
└── README.md
```

## ✨ Features

* Personal profile homepage
* About Me section
* Skills displayed as a list
* Projects section with clickable links
* Responsive design for desktop and mobile
* Separate CSS stylesheet
* No inline `style` attributes
* CSS variables for background, text, and accent colors
* Link hover and focus effects
* Project-card mouse hover effects
* Accessible focus states for keyboard navigation
* Placeholder values marked with `PLACEHOLDER` for easy editing

## 🛠️ Technologies Used

* **HTML5** — Page structure and semantic content
* **CSS3** — Styling, layout, colors, responsiveness, and hover effects

## 🎨 Color & Contrast

The main colors are defined at the top of `style.css` using CSS variables:

```css
:root {
    --background: #F4F7FB;
    --surface: #FFFFFF;
    --text: #172033;
    --muted-text: #4B5563;
    --accent: #1D4ED8;
    --accent-hover: #1E40AF;
}
```

These colors are used consistently for the page background, text, links, buttons, and project cards.

## 🚀 How to Run

1. Download or clone the project.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in any modern web browser.

No additional software or installation is required.

## ✏️ Customization

Search for `PLACEHOLDER` in `index.html` and replace those values with your own information.

You can customize:

* Personal introduction
* Skills
* Project names
* Project descriptions
* Project links
* Email address
